# Волшебный ящик желаний

Веб-приложение для сбора желаний сотрудников с суммами и вложениями.

## Локально

```bash
npm install
env -u DATABASE_URL npm run dev
```

Откройте http://127.0.0.1:3000

- Главная (3D-ящик): `/`
- Выбор суммы: `/amounts`
- Форма желания: `/wish?amount=5000`
- Админ (желания): `/admin`
- Справочник: `/admin/staff`

Для проверки админки задайте `ADMIN_PASSWORD` в окружении (без него вход недоступен):

```bash
ADMIN_PASSWORD='your-local-password' env -u DATABASE_URL npm run dev
```

В опубликованном приложении задайте `ADMIN_PASSWORD` через Secrets Cursor.

## Данные

Штат и желания хранятся в Postgres (`cursor-app.json` + `migrations/`). Без `DATABASE_URL` используется PGlite в памяти процесса.

Начальный штат подгружается на сервере из внутреннего модуля (не публичный JSON). Полный справочник доступен только после входа администратора; публичная форма делает lookup отдела по имени и должности.

Желание хранит сумму, текст, опциональную ссылку и изображение (BYTEA, до 5 МБ). Вход в админку и отправка желаний ограничены по IP.
