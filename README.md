# Волшебная коробка желаний

Веб-приложение для сбора желаний сотрудников с суммами и вложениями.

## Локально

```bash
npm install
env -u DATABASE_URL npm run dev
```

Откройте http://127.0.0.1:3000

- Главная (3D-коробка): `/`
- Выбор суммы: `/amounts`
- Форма желания: `/wish?amount=5000`
- Админ (желания): `/admin`
- Справочник: `/admin/staff`

Секреты для локальной проверки (без них админ-вход и сохранение сотрудника недоступны):

```bash
SESSION_SECRET='dev-local-only' ADMIN_PASSWORD='your-local-password' env -u DATABASE_URL npm run dev
```

В опубликованном приложении задайте через Secrets Cursor:
- `ADMIN_PASSWORD` — вход в админку
- `SESSION_SECRET` — подпись cookie сотрудника (обязательно)
- `STAFF_SEED_JSON` — опционально: JSON `{ "departments": [...] }` с реальным штатом для первого seed пустой БД

## Данные

Штат и желания хранятся в Postgres (`cursor-app.json` + `migrations/`). Без `DATABASE_URL` используется PGlite в памяти процесса.

Начальный штат читается только на сервере (`server-only`): из `STAFF_SEED_JSON`, иначе — вымышленный demo-набор в коде (без реальных ФИО). Полный справочник в UI — только после входа администратора; публично доступен лишь lookup отдела по имени и должности.

Желание хранит сумму, текст, опциональную ссылку и изображение (BYTEA, до 5 МБ). Вход в админку и отправка желаний ограничены по IP.
